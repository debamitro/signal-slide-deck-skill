# Signal slide deck skill

This is a skill created out of the bigger [frontend slides skill](https://github.com/zarazhangrui/frontend-slides) by Zara Zhang.

* Based on the Signal template
* Optimized for print-readiness
* Made for slide decks

## How to use it

Load the skill in your agent, in whichever way it loads skills. You can also read in the SKILL.md as part of your prompt.

## How I created this

I used my own [CLI agent](https://github.com/debamitro/one-shot-cli-agent) and GLM 4.7. It took me $0.78 to build a slide deck and also to create this skill
